# NarSil-Q data

NarSil-Q is NarSil played with the content and rules of **Sil-Q**
(<https://github.com/sil-quirk/sil-q>), a continuation of Sil 1.3 by the Sil-Q team
(see Sil-Q's `lib/docs/CHANGELOG.md` for its many contributors). Sil-Q and NarSil
share the same licence (GPL-2 / the Angband licence); the Sil-Q content here is
converted from Sil-Q 1.5.1's `lib/edit/*.txt` with credit and thanks.

This directory is an **overlay**: it holds only the files that differ from `../lib`.
The game's lib dir for NarSil-Q is `../lib` with these files copied over it
(`tools/merge-lib.sh`).

## Playing it

Build NarSil as usual (for example `./configure --with-no-install && make`), then run
`tools/narsil-q.sh`, giving it the usual front-end arguments (`tools/narsil-q.sh -mgcu`). It merges the
data into `build-silq/lib` and keeps NarSil-Q's saves and scores in `build-silq/user`, apart from NarSil's.
The savefiles carry their own tag (USLQ), so neither game will load the other's characters.

Sil-Q's Fletchery command is on `-`, as in Sil-Q.

What differs:

- `gamedata/constants.txt`: `game:silq` (its own savefiles) and Sil-Q's rules: items on the
  floor shed no light (only the Iron Crown does); staffs need no Will check; guaranteed forges
  at 100', 300' and 500'; an adaptive minimum-depth clock; Morgoth grows angrier in stages.
- `gamedata/race.txt`, `house.txt`: Sil-Q's racial affinities, the Edain's curved sword, its house names.
- `gamedata/monster.txt`: Sil-Q's 148 monsters (thralls, skirmishers, wraiths, ...), with the
  spells HATCH_SPIDER, DIM, THROW_WEB and RALLY.
- `gamedata/object.txt`, `special.txt`, `artefact.txt`: Sil-Q's numbers, egos and artefacts, its
  rings, amulets, staffs and cone-shaped horns.
- `gamedata/ability.txt`, `song.txt`: Sil-Q's ability tree and its four extra songs.
- `gamedata/vault.txt`: Sil-Q's vaults (sunlight, thrall pits).
- `tiles/microchasm/graf-mcm.prf`: tile list for the monsters NarSil-Q has.

All of it is generated by `tools/silq-convert.py` from Sil-Q's files and reviewed by hand;
the build never reads Sil-Q's files.

Not ported: the staff of Self Knowledge (the abilities screen already lists everything it would), the light
curse (in Sil-Q it marks an item cursed, keeps it out of "good" rolls and lowers a cursed special's smithed pval;
it has no effect of its own), the throne-room crowds shying from the player (Sil-Q gives no mechanism beyond what
NarSil already has) and the +1 score for not using fixed experience.

Differs on purpose: oaths are sworn through yes/no prompts, not Sil-Q's menu; Delvings shows stairs, forges and
traps as Sil-Q's code intends, without its indexing slip; the horn of Blasting's wall-breaking arc may not match
Sil-Q's grid for grid. Checked against Sil-Q's code: floor light (only the Iron Crown) and staffs (no Will check;
Sil-Q's only use check is on activation).
